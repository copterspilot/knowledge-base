### **Как правильно поставить задачу: "Создай слайды по шаблону"**

1.  **Укажите источник шаблона:**
    *   **Хорошо:** "Создай слайды по шаблону из файла `04 Шаблон слайда.md`."
    *   **Еще лучше:** "Используй шаблон из прикрепленного файла `04 Шаблон слайда.md`. В нем указано, что часть 'Содержимое слайда (для PowerPoint)' должна быть обернута в Markdown."

2.  **Четко определите, какая часть должна быть в Markdown:**
    *   **Идеально:** "Оберни в Markdown **только** блок с заголовком `## [Номер] [Наименование слайда]` и следующий за ним блок `**Содержимое слайда (для PowerPoint):**`. Весь остальной текст должен быть в обычном формате."

3.  **Уточните цель форматирования:**
    *   **Полезно:** "Оберни эту часть в Markdown, чтобы я мог легко скопировать и вставить ее в Obsidian/документ."

4.  **Предоставьте пример ожидаемого результата:**
    *   **Лучший способ:** "Вот пример того, как должен выглядеть слайд (см. ниже). Пожалуйста, следуй этой структуре для всех последующих слайдов."

---

### **Пример идеальной формулировки задачи**

> "Создай первый слайд для презентации 'Обеспечение безопасности в Kubernetes' по шаблону из прикрепленного файла `04 Шаблон слайда.md`.
>
> **Важно:** Оберни в блок Markdown **только** следующие два элемента:
> ```
> ## [1] Титульный слайд
>
> **Содержимое слайда (для PowerPoint):**
> - **Заголовок:** ...
> - **Подзаголовок:** ...
> ```
>
> Остальной текст (Уровень сложности, Цель слайда и т.д.) должен быть в обычном формате.
>
> Цель: я хочу легко копировать только ту часть, которую нужно вставить в PowerPoint, не копируя вспомогательные инструкции."
