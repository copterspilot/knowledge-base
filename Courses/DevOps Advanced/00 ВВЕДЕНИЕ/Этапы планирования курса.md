# Промты для создания и наполнения Trainer Book

## Промт 1: Определение метаданных и стратегии вебинара

**Цель:** Заложить фундаментальную основу вебинара, определив его место в общей структуре курса/программы и понять, для кого мы работаем.

**Участники обсуждения:** Продюсер, Спикер, Методист

**Ключевые вопросы для обсуждения:**

1.  **Идентификация:**
    *   Присвойте вебинару уникальный `ID` (например, `AWS-CLOUD-101`). Какой шаблон именования мы используем?
    *   Каково **окончательное название вебинара** для анонса и внутреннего использования? Оно должно быть цепляющим и отражать суть.
    *   К какой **серии вебинаров** или **курсу** относится это занятие? Является ли оно частью большой программы?

2.  **Целевая аудитория (ЦА):**
    *   Опишите портрет идеального участника этого вебинара максимально конкретно.
    *   Какой у него **опыт** в данной теме? (начинающий, middle, senior)?
    *   Какие **технические навыки** и **знания** мы от него ожидаем? Что он уже должен знать?
    *   Какие **роли** у этой аудитории? (Разработчик, DevOps, аналитик, менеджер)?
    *   Какие **боли** и **запросы** есть у этой аудитории, которые мы решаем?

3.  **Стратегические цели:**
    *   Какой **главный вывод** должен сделать участник после этого вебинара?
    *   Как это занятие продвигает его к цели всего курса?

**Результат выполнения промта:** Заполненный первый раздел Trainer Book с согласованными метаданными и пониманием ЦА.

## Промт 2: Декомпозиция и категоризация целей обучения

**Цель:** Четко определить и структурировать, какие именно знания и навыки получат участники, установив границы ответственности данного вебинара.

**Участники обсуждения:** Спикер, Методист

**Инструкция:** На основе утвержденной темы и ЦА, давайте сформулируем цели обучения (Learning Objectives). Формулируйте цели через глаголы действия (объяснить, создать, сравнить, проанализировать). Разделим их на категории:

*   **Базовые (Обязательные):** Цели, без достижения которых вебинар не состоялся. Минимум, который должен усвоить каждый.
*   **Продвинутые (Желательные):** Цели, которые мы планируем достичь, если позволит время и уровень вовлеченности аудитории.
*   **Экспертные (На вырост):** Цели для самых любознательных. Глубокие нюансы, лайфхаки, о которых мы упомянем, если все пойдет по плану.
*   **Связанные (Смежные):** Темы, которые тесно связаны с нашей, но мы их лишь кратко затронем или упомянем для контекста.
*   **Не обсуждаем (Out of Scope):** Темы, которые сознательно вынесены за рамки этого вебинара, чтобы не перегружать аудиторию. Укажите, где они будут рассмотрены (например, "эта тема подробно разбирается в вебинаре `WEB-DEV-205`").

**Вопрос для промта:** "Используя инструкцию выше, предложите и categorizуйте 5-7 ключевых целей обучения для вебинара `[Название вебинара]`."

**Результат выполнения промта:** Четкий, измеримый список целей, который станет основой для создания контента и слайдов.

## Промт 3: Формирование списка литературы и открытых ресурсов

**Цель:** Создать надежную опору для содержания вебинара, обеспечить его достоверность и дать участникам проверенные точки для углубленного изучения темы после занятия.

**Участники обсуждения:** Спикер

**Инструкция:** Для обеспечения высокого качества контента и доверия аудитории, составьте список источников, которые вы используете при подготовке и которые порекомендуете участникам. Для каждого источника укажите:

1.  **Тип ресурса:** Официальная документация, книга (с ISBN или ссылкой), статья в блоге, научная работа, репозиторий GitHub, видео и т.д.
2.  **Название и автор/издатель.**
3.  **Ссылка** (если применимо).
4.  **Краткое пояснение:** Почему вы доверяете этому источнику и для раскрытия какого аспекта темы он используется/рекомендуется?

**Вопрос для промта:** "На основе плана вебинара `[Название вебинара]`, составьте структурированный список как минимум из 5 ключевых источников (официальная документация, книги, авторитетные блоги), которые будут использованы для подготовки и рекомендованы участникам для углубления знаний."

**Результат выполнения промта:** Проверенный и одобренный список ресурсов для раздела "Дополнительные материалы" в Trainer Book.

## Промт 4: Определение структуры описания слайдов презентации

**Цель:** Создать унифицированный и максимально полезный шаблон для синхронизации повествования спикера с визуальным рядом. Это "сценарий" для каждого слайда.

**Участники обсуждения:** Спикер, Методист, Дизайнер (опционально)

**Инструкция:** Для эффективной работы над презентацией нам нужна единая структура описания каждого слайда. Предлагаем следующий шаблон для таблицы в нашем документе:

| № слайда | Заголовок слайда (макет) | Ключевые тезисы / Речь спикера                               | Демонстрации / Действия            | Визуальный ряд / Примечания для дизайнера   | Тайминг (мин) |
|:-------- |:------------------------ |:------------------------------------------------------------ |:---------------------------------- |:------------------------------------------- |:------------- |
| 1        | Титульный                | "Добрый день, меня зовут... Сегодня мы поговорим о..."       | Включить камеру, улыбнуться        | ФИО, название вебинара, логотип компании    | 2             |
| 3        | Что такое X?             | "Давайте дадим определение... Главные характеристики это..." | Переключить на доску Miro с схемой | Схема с основными компонентами, иконографии | 5             |

**Вопрос для промта:** "Мы договорились использовать для описания презентации структуру с колонками: [№ слайда, Заголовок, Тезисы/Речь, Демо/Действия, Визуал/Примечания, Тайминг]. Для вебинара `[Название вебинара]` распиши, пожалуйста, по этой структуре содержание первых 3-х слайдов (приветствие, план, введение в проблему), чтобы задать стандарт для всей остальной презентации."

**Результат выполнения промта:** Утвержденный шаблон для раздела "Детальный тайминг и сценарий" в Trainer Book, готовый к заполнению всеми слайдами.
