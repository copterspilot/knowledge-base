### 🔹 **Официальная документация (обязательно к изучению)**
1. **[Kubernetes Official Documentation — Debugging Kubernetes](https://kubernetes.io/docs/tasks/debug/debug-application/)**  
   - Основа всего: диагностика Pod'ов, логов, событий, конфигураций.
   - Разделы: `Debug Pods`, `Debug Services`, `Debugging with kubectl describe`, `kubectl logs`, `kubectl exec`.

2. **[Troubleshooting Clusters](https://kubernetes.io/docs/tasks/debug/debug-cluster/)**  
   - Диагностика проблем на уровне узлов, kubelet, control plane, CNI, DNS.

3. **[kubectl Cheat Sheet](https://kubernetes.io/docs/reference/kubectl/cheatsheet/)**  
   - Полезно включить в занятие как шпаргалку для студентов.

### 🔹 **Статьи и блоги**
1. **[Learnk8s — Debugging Kubernetes](https://learnk8s.io/)**  
   - Серия статей:  
     - ["How to debug Kubernetes deployments"](https://learnk8s.io/debug-kubernetes-deployments)  
     - ["Debugging Kubernetes services"](https://learnk8s.io/debug-kubernetes-services)  
     - ["5 common mistakes in Kubernetes"](https://learnk8s.io/5-common-mistakes-kubernetes)  
   - Очень наглядные примеры, диаграммы, пошаговые инструкции.

2. **[Brendan Burns — "Debugging Distributed Systems"](https://blog.brendanburns.com/)**  
   - Один из создателей Kubernetes. Пишет о принципах диагностики в распределённых системах.

3. **[Ahmet Alp Balkan — kubectl tips](https://ahmet.im/blog/kubectl-tips/)**  
   - Полезные советы по эффективному использованию `kubectl` для отладки.

4. **[Sysdig Blog — Kubernetes Troubleshooting](https://sysdig.com/blog/category/kubernetes/)**  
   - Глубокие технические статьи: отладка сетей, безопасность, производительность.

5. **[Red Hat — Debugging Kubernetes applications](https://www.redhat.com/en/topics/containers/how-to-debug-kubernetes-applications)**  
   - Структурированный подход с примерами.
