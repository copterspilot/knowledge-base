## 45. Глоссарий: термины и определения

**Содержимое слайда (для PowerPoint):**
- **Заголовок:** Глоссарий: термины и определения
- **Основной текст (алфавитный список):**
  - **CNI (Container Network Interface):** Плагин, отвечающий за сетевое подключение контейнеров в кластере (Calico, Cilium, Weave Net).
  - **CrashLoopBackOff:** Состояние пода, при котором контейнер запускается, падает, и Kubernetes ждет перед следующей попыткой перезапуска.
  - **eBPF (extended Berkeley Packet Filter):** Технология ядра Linux, позволяющая безопасно запускать программы для мониторинга и фильтрации сети, системных вызовов и т.д.
  - **Helm:** Менеджер пакетов для Kubernetes, позволяющий упаковывать, версионировать и развертывать приложения.
  - **Hubble:** Инструмент для визуализации и мониторинга сетевой активности в кластерах Cilium на основе eBPF.
  - **krew:** Официальный менеджер плагинов для `kubectl`.
  - **kubectl:** Основной CLI-инструмент для взаимодействия с кластером Kubernetes.
  - **Pod:** Наименьшая развертываемая единица в Kubernetes, которая может содержать один или несколько контейнеров.
  - **Service:** Объект Kubernetes, который предоставляет стабильный IP-адрес и DNS-имя для набора подов.
  - **TUI (Text-based User Interface):** Текстовый пользовательский интерфейс, работающий в терминале (`k9s`).
- **Визуал:** Иконка "словаря" или "книги".
- **Подпись:** "Понимание терминов — ключ к пониманию системы"

- **В:** В чем разница между Pod и контейнером?

- **В:** Что делает CNI?  
  **О:** Он отвечает за IP-адресацию, маршрутизацию и сетевые политики для подов.
- **В:** Зачем нужен Helm?
