## 40. Cheatsheet: Отладка в Kubernetes

**Содержимое слайда (для PowerPoint):**
- **Заголовок:** Cheatsheet: Отладка в Kubernetes
- **Основной текст (таблица / список):**

  **1. Первичный осмотр:**
  - `kubectl get pods -A` → Все поды
  - `kubectl get nodes` → Состояние узлов
  - `kubectl get events --sort-by=.metadata.creationTimestamp` → События кластера
  - `kubectl top node` / `pod` → Потребление ресурсов

  **2. Глубокая диагностика:**
  - `kubectl describe pod <имя>` → **События (Events)**, конфигурация
  - `kubectl logs <имя>` → Логи приложения
  - `kubectl logs <имя> --previous` → Логи упавшего контейнера
  - `kubectl logs -l app=frontend` → Логи по метке

  **3. Интерактивная отладка:**
  - `kubectl exec -it <имя> -- sh` → Вход в контейнер
  - `kubectl port-forward pod/<имя> 8080:80` → Доступ к сервису
  - `kubectl debug -it <имя> --image=busybox` → Отладка в `distroless` образе

  **4. Полезные инструменты:**
  - `stern frontend` → Агрегация логов с цветами
  - `k9s` → TUI для быстрой диагностики
  - `krew list` → Список установленных плагинов

- **Визуал:** Скриншот терминала с оформленным cheatsheet (можно в виде ASCII-арта).
- **Подпись:** "Ваша шпаргалка для повседневной работы"
