### **Статья 10: Выполнение команд - `kubectl exec`, `attach`, `cp`**

#### **Введение**

Когда вы хотите посмотреть, что происходит внутри контейнера, вы используете `kubectl exec`. Это как `docker exec`, но для Kubernetes. Это основной способ "войти" в контейнер для диагностики. В этой статье мы рассмотрим три команды, которые позволяют вам взаимодействовать с контейнерами: `exec`, `attach` и `cp`. Эти команды являются основой для отладки, но помните, что они бесполезны, если в контейнере нет `sh` или `bash`.

#### **`kubectl exec`: Выполнение команды внутри контейнера**

Команда `exec` — это ваш основной инструмент для выполнения команд внутри запущенного контейнера.

*   **Что делает:** Запускает команду в контейнере и возвращает её вывод.
*   **Интерактивный режим:** Используется для запуска оболочки (`sh`, `bash`). Флаги `-it` означают:
    *   `-i` (interactive): сохраняет stdin открытым.
    *   `-t` (tty): выделяет псевдо-TTY.
*   **Примеры:**
    ```bash
    # Запустить интерактивную оболочку в контейнере
    kubectl exec -it my-pod -- /bin/sh
    
    # Выполнить одну команду и выйти
    kubectl exec my-pod -- ps aux
    
    # Выполнить команду в конкретном контейнере (в поде с несколькими контейнерами)
    kubectl exec my-pod -c my-container -- df -h
    ```

#### **`kubectl attach`: Подключение к основному процессу**

Команда `attach` используется для подключения к стандартным потокам ввода-вывода (stdin/stdout) *уже запущенного основного процесса* в контейнере.

*   **Что делает:** Подключает ваш терминал к stdin/stdout основного процесса.
*   **На что смотреть:** Вывод самого приложения, который может не писаться в файлы логов.
*   **Пример:**
    ```bash
    # Подключиться к основному процессу в контейнере
    kubectl attach my-pod -c my-container -i -t
    ```
    *   **Важно:** Чтобы отключиться, часто нужно отправить `Ctrl+P, Ctrl+Q`.

#### **`kubectl cp`: Копирование файлов**

Команда `cp` позволяет копировать файлы между вашей локальной машиной и файловой системой контейнера.

*   **Что делает:** Использует утилиту `tar` внутри контейнера для архивации и извлечения файлов.
*   **Примеры:**
    ```bash
    # Скопировать файл из контейнера на локальную машину
    kubectl cp my-pod:/app/config.json ./config.json
    
    # Скопировать файл с локальной машины в контейнер
    kubectl cp ./debug.sh my-pod:/tmp/debug.sh
    
    # Скопировать весь каталог (с флагом -r)
    kubectl cp -r ./local/dir my-pod:/remote/dir
    ```
*   **Ограничение:** Требует, чтобы в контейнере была установлена утилита `tar`.

#### **Заключение**

Эти команды — ваш "набор отверток" для диагностики. Используйте `exec` для запуска команд, `attach` для просмотра вывода процесса и `cp` для передачи файлов. Однако помните об их главном ограничении: они не работают в `distroless` образах. В следующей статье мы рассмотрим `kubectl debug`, который решает эту проблему с помощью ephemeral-контейнеров.
