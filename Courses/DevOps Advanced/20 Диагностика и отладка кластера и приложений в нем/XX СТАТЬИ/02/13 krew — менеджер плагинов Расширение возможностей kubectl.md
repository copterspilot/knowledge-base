### **Статья 13: `krew` — менеджер плагинов: Расширение возможностей `kubectl`**

#### **Введение**

Команды `kubectl`, которые мы уже знаем, мощны, но иногда нам нужно больше. Вот тут и приходит `krew`. Это официальный менеджер плагинов от Kubernetes SIG CLI. С его помощью вы можете одним кликом установить десятки полезных инструментов. Использование `krew` значительно расширяет ваш арсенал. Это как установить менеджер пакетов (`apt`, `brew`) в вашу операционную систему.

#### **Что такое `krew`?**

`krew` — это `apt` или `brew` для плагинов `kubectl`. Он решает проблему сложной установки и обновления сторонних инструментов.

*   **Установка:** `krew` устанавливается один раз. После этого вы можете устанавливать и обновлять плагины одной командой.
*   **Репозиторий:** `krew` имеет центральный каталог (index) с сотнями плагинов.
*   **Безопасность:** `krew` проверяет подписи плагинов, что повышает безопасность.

#### **Почему `krew` необходим?**

Без `krew` установка сторонних инструментов — это ручной процесс:
1.  Найти репозиторий на GitHub.
2.  Скачать бинарник.
3.  Поместить его в `PATH`.
4.  Следить за обновлениями вручную.

`krew` автоматизирует все эти шаги, превращая установку в одну команду.

#### **Практические примеры популярных плагинов**

1.  **`kubectl debug`:**
    ```bash
    # Установка плагина
    kubectl krew install debug
    # Использование (создание ephemeral-контейнера)
    kubectl debug my-pod -it --image=busybox
    ```
    Этот плагин, который мы уже рассмотрели, — один из самых востребованных.

2.  **`kubectl sniff` (для `ksniff`):**
    ```bash
    kubectl krew install sniff
    kubectl sniff my-pod
    ```
    Упрощает захват сетевого трафика и его передачу в Wireshark.

3.  **`kubectl view-utilization`:**
    ```bash
    kubectl krew install view-utilization
    kubectl view-utilization node
    ```
    Предоставляет более наглядную визуализацию потребления ресурсов, чем `kubectl top`.

4.  **`kubectl who-can`:**
    ```bash
    kubectl krew install who-can
    kubectl who-can create pods --as=dev-user
    ```
    Помогает в отладке политик RBAC, показывая, кто может выполнять определенные действия.

#### **Заключение**

`krew` — это must-have инструмент для любого инженера, который работает с Kubernetes. Он превращает `kubectl` из базового молотка в полноценный инструментальный ящик. Установив `krew`, вы получаете легкий доступ к сотням полезных утилит, которые значительно упрощают диагностику, отладку и управление кластером. В следующей статье мы рассмотрим `kubectl edit` — команду для быстрых правок, но с серьезными рисками.
