### **Статья 6: Анализ сетевого трафика: `ksniff` (Wireshark для Kubernetes)**

#### **Введение**

Представьте, что ваш сервис не может подключиться к базе данных. Вы проверили `describe` и `logs`, но ответа нет. Что делать? Вам нужно заглянуть 'на провод'. Для этого существует `ksniff`. Это как `kubectl exec`, но вместо запуска команды он запускает `tcpdump` и передает захваченные пакеты напрямую в ваш локальный Wireshark. Это один из самых эффективных способов диагностики сетевых проблем.

#### **Проблема: Невидимость сетевого трафика**

В традиционной архитектуре сетевые инженеры используют анализаторы пакетов (sniffers) для диагностики проблем. В Kubernetes поды изолированы, и прямой доступ к сетевому интерфейсу невозможен. Это создает слепое пятно при диагностике DNS-запросов, TCP-соединений и TLS-рукопожатий.

#### **Решение: `ksniff` — Wireshark для Kubernetes**

`ksniff` — это плагин для `kubectl`, который решает эту проблему, объединяя мощь `tcpdump` и удобство графического интерфейса `Wireshark`.

*   **Что делает:** `ksniff` автоматизирует процесс захвата сетевого трафика с пода.
*   **Как это работает:**
    1.  Вы запускаете команду `kubectl sniff`.
    2.  `ksniff` создает специальный контейнер с утилитой `tcpdump` внутри целевого пода (или рядом с ним).
    3.  `tcpdump` начинает захватывать пакеты.
    4.  Поток данных передается напрямую на ваш локальный компьютер и открывается в запущенном `Wireshark`.
*   **Преимущества:**
    *   **Графический интерфейс:** Анализировать трафик в `Wireshark` гораздо удобнее, чем в сыром выводе `tcpdump`.
    *   **Простота:** Одна команда заменяет сложный ручной процесс.
    *   **Безопасность:** Использует существующее соединение к API-серверу.

#### **Практический пример**

1.  Установите `ksniff` как плагин `krew`:
    ```bash
    kubectl krew install sniff
    ```
2.  Запустите `Wireshark` на вашем компьютере.
3.  Выполните команду:
    ```bash
    kubectl sniff my-app-pod-7d5b8c9c4-xl2v9 -n default
    ```
    В окне `Wireshark` вы увидите все сетевые пакеты, проходящие через этот под. Вы можете фильтровать по протоколу (DNS, TCP, HTTP), анализировать задержки и искать ошибки.

#### **Заключение**

`ksniff` — это незаменимый инструмент для диагностики сетевых проблем. Он позволяет вам увидеть "на проводе" то, что невозможно обнаружить с помощью стандартных команд `kubectl`. В следующей статье мы рассмотрим `inspektor-gadget`, который использует технологию eBPF для еще более глубокой интроспекции.
