**1. Визуальный ряд:**
*   Схема работы ksniff: Pod -> tcpdump -> Wireshark
*   Скриншот Wireshark с перехваченным трафиком из пода
*   Диаграмма архитектуры eBPF и Inspektor-Gadget
*   Пример вывода `ig trace open` для трассировки системных вызовов
*   Логотипы инструментов: ksniff, Inspektor-Gadget, Wireshark

**2. Демо-сценарий:**
*   Краткая демонстрация возможностей:
    ```bash
    # Захват трафика из пода в Wireshark
    kubectl sniff my-pod -n my-namespace -p -o ./capture.pcap
    
    # Трассировка системных вызовов открытия файлов
    kubectl gadget trace open -n my-namespace --podname my-pod
    
    # Профилирование CPU использования
    kubectl gadget profile cpu -n my-namespace --podname my-pod
    ```

**3. Ключевые тезисы:**
*   "Ksniff — мост между Kubernetes и Wireshark для анализа сетевого трафика"
*   "Inspektor-Gadget использует eBPF для глубокой диагностики без модификации подов"
*   "eBPF позволяет безопасно наблюдать за системой на уровне ядра"
*   "Эти инструменты — для случаев когда стандартные методы не работают"
*   "Требуют привилегированных доступов и понимания сетевых/системных процессов"
