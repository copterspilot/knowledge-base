| Устаревшее        | Современная замена                     |
| ----------------- | -------------------------------------- |
| `kubectl exec`    | `kubectl debug` + ephemeral containers |
| Ручные аудиты     | Automated shift-left scanning          |
| PSP               | Kyverno/OPA                            |
| Кастомные скрипты | KUTTL, Terratest                       |

**2. Демо-сценарий:**
*   Показать примеры устаревших подходов и их современные аналоги:
    ```bash
    # Устаревшее: Глубокий exec в продакшене
    kubectl exec -it production-pod -- /bin/bash
    
    # Современное: Безопасная отладка
    kubectl debug -it production-pod --image=debug-tools --share-processes --copy-to=debug-pod
    ```

**3. Ключевые тезисы:**
*   "kubectl exec как основной метод отладки умер — используйте ephemeral containers"
*   "Ручные проверки безопасности не масштабируются — только автоматизация"
*   "Pod Security Policies официально deprecated — переходите на Kyverno/OPA"
*   "Кастомные bash-скрипты для тестирования заменяются на KUTTL/Terratest"
*   "Монолитные решения уступают место специализированным инструментам"

**6. Типовые вопросы и ответы (Q&A):**
*   **В:** Что делать если мы до сих пор используем PSP?
    *   **О:** Срочно мигрировать на Kyverno, PSP удалят в будущих версиях K8s
*   **В:** Почему kubectl exec считается устаревшим?
    *   **О:** Это небезопасно, меняет состояние пода и не работает с минимальными образами
*   **В:** Как убедить команду обновиться?
    *   **О:** Показать риски безопасности и потерю совместимости

**7. Типовые примеры/сценарии:**
