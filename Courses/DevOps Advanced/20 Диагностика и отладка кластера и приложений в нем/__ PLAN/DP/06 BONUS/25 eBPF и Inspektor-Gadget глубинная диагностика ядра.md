**1. Визуальный ряд:**
*   Архитектурная схема eBPF: Пользовательское пространство -> eBPF программы -> Ядро Linux
*   Диаграмма возможностей Inspektor-Gadget:
    *   **Трассировка:** syscall, network, capability changes
    *   **Профилирование:** CPU, memory, disk I/O
    *   **Аудит безопасности:** file access, process execution
*   Скриншот вывода `kubectl gadget trace` для системных вызовов
*   Сравнительная таблица eBPF-инструментов:
   
| Инструмент           | Уровень    | Требуемые права | Use-case                    |
| -------------------- | ---------- | --------------- | --------------------------- |
| **Inspektor-Gadget** | Kubernetes | Низкие          | K8s-нативная диагностика    |
| **BCC**              | Node       | Elevated        | Глубокая диагностика узла   |
| **bpftrace**         | Node       | Elevated        | Скриптование и адхок анализ |

**2. Демо-сценарий:**
*   Демонстрация возможностей Inspektor-Gadget:
    ```bash
    # Трассировка системных вызовов открытия файлов
    kubectl gadget trace open -n my-namespace --podname my-pod
    
    # Мониторинг сетевых соединений
    kubectl gadget trace network -n my-namespace --podname my-pod
    
    # Профилирование CPU
    kubectl gadget profile cpu -n my-namespace --podname my-pod -o flamegraph.html
    ```
*   Показать работу с BCC для продвинутой диагностики:
    ```bash
    # Просмотр системных вызовов в реальном времени
    execsnoop-bpfcc
    
    # Анализ задержек диска
    bitesize-bpfcc
    ```

**6. Типовые вопросы и ответы (Q&A):**
*   **В:** Насколько безопасно использовать eBPF в продакшене?
    *   **О:** Очень безопасно — eBPF имеет verifier который гарантирует безопасность программ
*   **В:** Нужны ли специальные ядра для eBPF?
    *   **О:** Современные ядра (4.9+) поддерживают eBPF, но лучшие возможности в 5.x+
*   **В:** Как начать использовать Inspektor-Gadget?
    *   **О:** Установить через krew: `kubectl krew install gadget`
