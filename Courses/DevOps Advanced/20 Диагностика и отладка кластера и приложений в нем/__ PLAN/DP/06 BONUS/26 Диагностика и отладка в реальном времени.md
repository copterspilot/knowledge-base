### **26 Диагностика и отладка в реальном времени**

**1. Визуальный ряд:**
*   Интерактивная архитектурная схема: Источники данных -> Стриминг -> Анализ -> Визуализация
*   Таблица инструментов реального времени:
    
    | Инструмент   | Тип данных            | Задержка | Интеграции          |
    | ------------ | --------------------- | -------- | ------------------- |
    | **Pixie**    | Metrics, Logs, Traces | <1s      | Kubernetes Native   |
    | **Perses**   | Metrics               | <5s      | Prometheus, Grafana |
    | **Headlamp** | Events, Resources     | <3s      | Kubernetes API      |
    | **K9s**      | Resources, Logs       | <2s      | Terminal UI         |
    
*   Скриншот дашборда Pixie с live-метриками и трассировкой
*   Пример вывода `kubectl live` или аналога

**2. Демо-сценарий:**
*   Live-демонстрация работы Pixie:
    ```bash
    # Установка Pixie CLI
    bash -c "$(curl -fsSL https://withpixie.ai/install.sh)"
    
    # Деploy Pixie в кластер
    px deploy
    
    # Просмотр live-метрик сервиса
    px run -s my-service
    ```
*   Показать K9s в действии:
    ```bash
    # Запуск K9s с фильтрацией
    k9s -n production --log-level debug
    ```

**6. Типовые вопросы и ответы (Q&A):**
*   **В:** Какой overhead у realtime-инструментов?
    *   **О:** Pixie использует eBPF с overhead <5%, K9s — практически нулевой
*   **В:** Нужно ли instrument код для Pixie?
    *   **О:** Нет — автоматическое наблюдение через eBPF и TLS tracing
*   **В:** Как выбрать между Pixie и Perses?
    *   **О:** Pixie для глубокой диагностики, Perses для метрик и alerting
