**1. Визуальный ряд**
*   Логотип `krew`.
*   Скриншот терминала: `kubectl krew` (с демонстрацией команд `list`, `search`, `install`).
*   Скриншот терминала: `kubectl krew list` (список установленных плагинов).
*   Иконки: магазин приложений, пазл (расширение).

**2. Демо-сценарий (если уместен)**
*   Показать в реальном времени команду `kubectl krew search` для поиска плагинов (например, `debug`, `sniff`).

**3. Ключевые тезисы**
*   `krew` — официальный менеджер плагинов для `kubectl`.
*   Он упрощает поиск, установку, обновление и удаление плагинов.
*   Плагины расширяют функциональность `kubectl`, интегрируясь в него как `kubectl <plugin-name>`.

**4. Описание (для выступающего)**
*   **Цель слайда:** Представить `krew` как центральный инструмент для расширения возможностей `kubectl`.
*   **Ключевое сообщение:** `krew` — это "App Store" для `kubectl`, который превращает его из базового CLI в мощную платформу.
*   **Основные тезисы:**
    *   `krew` — это проект, поддерживаемый Kubernetes SIG CLI, что делает его официальным способом установки плагинов.
    *   Он предоставляет репозиторий с сотнями проверенных плагинов.
    *   Основные команды:
        *   `kubectl krew search`: Поиск плагинов.
        *   `kubectl krew install <plugin>`: Установка плагина.
        *   `kubectl krew list`: Просмотр установленных плагинов.
        *   `kubectl krew upgrade`: Обновление всех установленных плагинов.
    *   После установки плагин становится доступен как `kubectl <plugin-name>` (например, `kubectl debug`, `kubectl sniff`).
*   **Связь с источниками:** Тезисы основаны на PDF 2019 года (слайд 4.1) и субтитрах (00:01:11 - 00:01:45).

**6. Типовые вопросы и ответы (Q&A)**
*   **В:** Где взять `krew`?
    *   **О:** Установка описана в официальной документации: `curl -fsSLO https://raw.githubusercontent.com/kubernetes-sigs/krew/master/install.sh && bash install.sh`. *(Из субтитров 2019: "как бы один раз сделав там штуку типа скурл, баш, что-то там такое")*.
*   **В:** Безопасны ли плагины из `krew`?
    *   **О:** Репозиторий `krew` тщательно модерируется. Устанавливайте только проверенные плагины из официального списка.
*   **В:** Какие плагины самые популярные?
    *   **О:** Среди самых популярных — `debug`, `sniff`, `stern`, `view-secret`, `view-utilization`. Мы рассмотрим `debug` и `sniff` далее.

**7. Примеры использования / Типовые сценарии**
*   Установка плагина `stern` для улучшенного просмотра логов: `kubectl krew install stern`.
*   Поиск плагинов для диагностики: `kubectl krew search debug`.
