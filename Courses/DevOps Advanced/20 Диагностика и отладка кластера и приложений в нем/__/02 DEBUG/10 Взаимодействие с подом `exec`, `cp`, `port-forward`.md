**3. Ключевые тезисы**
*   `kubectl exec` — запуск команд внутри контейнера.
*   `kubectl cp` — копирование файлов между локальной машиной и контейнером.
*   `kubectl port-forward` — проброс портов для доступа к сервисам внутри кластера.

**4. Описание (для выступающего)**
*   **Цель слайда:** Представить три основные команды для прямого взаимодействия с контейнерами и сервисами в кластере.
*   **Ключевое сообщение:** Эти команды — ваша "палочка-выручалочка" для быстрой диагностики и исправления проблем.
*   **Основные тезисы:**
    *   **`kubectl exec`:** Позволяет выполнить команду внутри контейнера. Ключ `-it` используется для интерактивного режима (например, `kubectl exec -it <pod> -- sh`). **Важно:** В минимальных образах (`scratch`, `distroless`) может не быть `sh` или `bash`.
    *   **`kubectl cp`:** Позволяет копировать файлы из локальной машины в контейнер и наоборот. Полезно для быстрого обновления конфигурации или извлечения логов.
    *   **`kubectl port-forward`:** Пробрасывает порт с локальной машины на порт в контейнере, сервисе или другом ресурсе. Трафик идет через `kube-apiserver`, поэтому не подходит для high-load сценариев.

**6. Типовые вопросы и ответы (Q&A)**
*   **В:** Работает ли `kubectl cp` с `initContainers`?
    *   **О:** Да, с помощью флага `--container=<имя_контейнера>`.
*   **В:** Что делать, если в контейнере нет `sh`?
    *   **О:** Использовать `kubectl debug` для запуска контейнера с полным набором утилит.
*   **В:** Можно ли пробрасывать порт на сервис?
    *   **О:** Да, `kubectl port-forward service/my-service 8080:80`. Однако трафик будет проброшен только на один из подов сервиса.

**7. Примеры использования / Типовые сценарии**
*   **Диагностика `CrashLoopBackOff`:** Использование `kubectl exec` для проверки конфигурации приложения.
*   **Обновление конфигурации:** Использование `kubectl cp` для копирования исправленного `config.yaml` в контейнер.
*   **Тестирование API:** Использование `kubectl port-forward` для доступа к внутреннему сервису через `localhost:8080`.

**8. Предложения по дополнительному контенту слайда**
