    - **Схема работы eBPF**:
        - Взаимодействие с ядром → сбор данных → анализ.
    - **Пример команды**:
         ```
         kubectl gadget trace exec <pod-name>
         ```

2. **Демо-сценарий**

3. **Ключевые тезисы**
    
    - **eBPF** — это технология для **глубокого анализа** работы ядра.
    - **Inspektor-Gadget** использует **eBPF** для мониторинга системных вызовов и событий.
    - Позволяет **отслеживать активность** на уровне ядра без значительных накладных расходов.
