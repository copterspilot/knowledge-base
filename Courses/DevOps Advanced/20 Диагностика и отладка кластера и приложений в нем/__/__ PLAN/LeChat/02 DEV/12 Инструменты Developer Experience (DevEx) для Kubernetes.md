#### **Описание слайда**

1. **Визуальный ряд**
    - **Логотипы инструментов**:
        - **Telepresence** (для локальной разработки с доступом к кластеру).
        - **Skaffold** (для автоматического развёртывания и обновления приложений).
        - **Tilt** (для визуализации процесса разработки).
        - **ksync** (для синхронизации файлов между локальной машиной и подом).
    - **Сравнительная таблица** инструментов:
        
| Инструмент   | Основное назначение                        | Преимущества                                   |
| ------------ | ------------------------------------------ | ---------------------------------------------- |
| Telepresence | Локальная разработка с доступом к кластеру | Быстрое тестирование, доступ к сервисам        |
| Skaffold     | Автоматическое развёртывание               | Интеграция с CI/CD, поддержка Helm и Kustomize |
| Tilt         | Визуализация процесса разработки           | Интерактивный UI, быстрая обратная связь       |
| ksync        | Синхронизация файлов                       | Быстрое обновление кода без пересборки         |
        
**Иконки**:
- 💻 — для локальной разработки.
- 🔄 — для автоматического развёртывания.
- 🎨 — для визуализации.
**Фон**: Светлый с акцентом на инструментах.

2. **Демо-сценарий** Показать **живые примеры**:
    - Использование **Telepresence** для подключения локального приложения к кластеру:
         ```
         telepresence connect
         ```
    - Запуск **Skaffold** для автоматического развёртывания:
         ```
         skaffold dev
         ```
    - Визуализация процесса разработки с **Tilt**:
         ```
         tilt up
         ```

---

3. **Ключевые тезисы**
    - **Telepresence**:
        - Позволяет **разрабатывать локально**, но с доступом к ресурсам кластера.
        - Поддерживает **прозрачный доступ** к сервисам и секретам.
    - **Skaffold**:
        - Автоматизирует **сборку, развёртывание и обновление** приложений.
        - Интегрируется с **Helm, Kustomize, Docker**.
    - **Tilt**:
        - Предоставляет **интерактивный UI** для визуализации процесса разработки.
        - Показывает **статус сборки и развёртывания** в реальном времени.
    - **ksync**:
        - Синхронизирует **файлы между локальной машиной и подом** без пересборки.
        - Ускоряет **итерации разработки**.
    - Эти инструменты **улучшают опыт разработки** и ускоряют процесс создания приложений для Kubernetes.

---

4. **Описание (для выступающего)**
    - **DevEx-инструменты** решают проблемы **медленной и сложной разработки** в Kubernetes.
    - **Telepresence** позволяет **разрабатывать локально**, но с доступом к кластеру, что ускоряет тестирование.
    - **Skaffold** автоматизирует **рутинные задачи** (сборка, развёртывание), освобождая время для разработки.
    - **Tilt** предоставляет **визуальный интерфейс**, который помогает отслеживать изменения и ошибки.
    - **ksync** ускоряет **обновление кода** в кластере без необходимости пересборки образов.
    - Важно подчеркнуть, что **выбор инструмента зависит от задач** и предпочтений команды.

5. **Связь с прошлыми материалами**
    - В презентации 2019 года упоминались **Telepresence** и **Skaffold** как инструменты для улучшения DevEx.
    - В чате обсуждались **проблемы с настройкой Telepresence** и преимущества **Tilt**.
    - Вопросы из чата:
        - _"Какой инструмент лучше для быстрой разработки?"_ → Зависит от задач: `Telepresence` для доступа к кластеру, `Tilt` для визуализации.
        - _"Можно ли использовать `ksync` с Windows?"_ → Да, но требуется настройка WSL или Docker.

6. **Типовые вопросы и ответы (Q&A)**
    - **Вопрос:** _"Какой инструмент выбрать для локальной разработки?"_ **Ответ:** `Telepresence` для доступа к кластеру, `Skaffold` для автоматического развёртывания.
    - **Вопрос:** _"Можно ли интегрировать `Tilt` с CI/CD?"_ **Ответ:** Да, `Tilt` поддерживает интеграцию с популярными CI/CD системами.
    - **Вопрос:** _"Как настроить `ksync` для синхронизации файлов?"_ **Ответ:** Следовать [официальной документации](https://ksync.github.io/ksync/).
