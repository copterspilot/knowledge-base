## 24. minikube и Dashboard

**Содержимое слайда (для PowerPoint):**
- **Заголовок:** minikube и Dashboard
- **Основной текст:**
  - **minikube** — инструмент для запуска локального кластера Kubernetes
  - Создает виртуальную машину (или использует Docker) с полноценным кластером
  - Поддержка плагинов: драйверы, CNI, ingress, метрики
  - **Dashboard** — веб-интерфейс для управления кластером
  - Просмотр ресурсов, логов, событий, масштабирование подов
  - Установка: `minikube dashboard`
- **Визуал:** Скриншот веб-интерфейса Kubernetes Dashboard.

#### **2. Ключевые тезисы (для аудитории)**
- `minikube` — это самый простой способ получить "настоящий" кластер.
- Он идеален для обучения, тестирования и разработки.
- Dashboard — это GUI для тех, кто не любит терминал.

#### **3. Ключевые тезисы (для преподавателя)**
- Подчеркните, что `minikube` создает полноценный, хотя и однодоменный кластер.
- Укажите, что Dashboard — это не production-инструмент, а средство для обучения.
- Напомните, что `minikube` можно настроить с разными драйверами (VirtualBox, Hyper-V, Docker).

#### **8. Типовые вопросы и ответы (Q&A)**
- **В:** В чем разница между `minikube` и Docker Desktop Kubernetes?  
  **О:** `minikube` более гибкий, поддерживает больше опций и CNI-провайдеров.
- **В:** Можно ли использовать `minikube` в production?  
  **О:** Нет, это инструмент для разработки и обучения.
- **В:** Как остановить `minikube`?  
  **О:** `minikube stop` — приостановит, `minikube delete` — удалит кластер.
