### **Схема: Архитектура Kubernetes: Control Plane и Worker Nodes**

```mermaid
graph TD
    subgraph Control_Plane["Control Plane (Плоскость управления)"]
        A[API Server]
        B[etcd]
        C[Планировщик<br/>(Scheduler)]
        D[Диспетчер контроллеров]
    end

    subgraph Worker_Node_1["Worker Node 1 (Рабочий узел)"]
        E[Kubelet]
        F[Kube-proxy]
        G[Container Runtime]
        H[Pod]
    end

    subgraph Worker_Node_N["Worker Node N (Рабочий узел)"]
        I[Kubelet]
        J[Kube-proxy]
        K[Container Runtime]
        L[Pod]
    end

    %% Связи внутри Control Plane
    A --> B
    A --> C
    A --> D
    C --> B
    D --> B

    %% Связи внутри Worker Node 1
    E --> G
    E --> H
    F --> H
    G --> H

    %% Связи внутри Worker Node N
    I --> K
    I --> L
    J --> L
    K --> L

    %% Связи между Control Plane и Worker Nodes
    A --> E
    A --> I
```

### **Пояснение к исправлениям:**

1.  **Имена узлов:** Заменил имена узлов с пробелами и специальными символами (например, `api_server`) на простые имена без пробелов (например, `A`, `B`). Для отображения текста используется квадратные скобки `[ ]`.
2.  **Названия подграфов:** Названия подграфов (`subgraph`) теперь являются простыми идентификаторами (например, `Control_Plane`), за которыми следует отображаемый текст в кавычках.
3.  **Переносы строк:** Для переноса строк внутри узлов использована конструкция `<br/>`, которая является стандартной в Mermaid.
4.  **Упрощение:** Убраны сложные стили (`classDef`), ссылки (`click`) и `linkStyle`, которые могут быть причиной ошибок в некоторых редакторах.
