#### **Цель слайда**
Показать аудитории, что для построения полноценной системы безопасности в CI/CD необходимо использовать несколько специализированных инструментов. Демонстрировать их различия и взаимодополняемость.

#### **1. Описание визуального оформления**
Слайд должен содержать четкую сравнительную таблицу 3x4. Используйте логотипы `Trivy`, `Checkov`, `GitLeaks` в заголовках столбцов. Фон таблицы — светлый, с черными границами. Внизу — иконка "экосистемы" (несколько взаимосвязанных шестеренок) и ключевая фраза.

#### **2. Ключевые тезисы**
*   Эти инструменты **не конкурируют, а дополняют друг друга**, образуя многоуровневую защиту.
*   `Trivy` фокусируется на **уязвимостях в образах**.
*   `Checkov` фокусируется на **анти-паттернах в конфигурации**.
*   `GitLeaks` фокусируется на **случайных секретах в коде**.

#### **3. Описание для выступающего (речь)**
"Эти три инструмента — как три фильтра на конвейере. Первый фильтр — `GitLeaks` — проверяет, не попал ли в кодовый репозиторий какой-либо секрет. Если найден — процесс останавливается. Второй фильтр — `Checkov` — проверяет, что манифесты Kubernetes соответствуют best practices. Третий фильтр — `Trivy` — проверяет сам образ на наличие уязвимостей. Использование всех трех инструментов создает надежную систему 'Shift-Left Security'."

#### **6. Типовые вопросы и ответы (Q&A):**
*   **В:** Можно ли использовать только один из этих инструментов?
    *   **О:** Нет. Каждый из них решает свою уникальную задачу. Отсутствие одного из уровней защиты оставляет брешь в вашей системе.
*   **В:** Есть ли инструмент, который делает всё?
    *   **О:** Некоторые платформы (например, Snyk, Aqua) объединяют эти функции, но в open-source экосистеме лучшей практикой считается использование специализированных инструментов.

#### **7. Примеры использования / Типовые сценарии**
*   **Интеграция в CI/CD:** Добавление всех трех инструментов в пайплайн для создания многоуровневого барьера.
*   **Аудит безопасности:** Проведение комплексного аудита репозитория с использованием всех трех инструментов.
