### **Глоссарий по занятию "Обеспечение безопасности в Kubernetes: Путь от конфигурации к автономной защите (2025)"**

---

**AIOps (Artificial Intelligence for IT Operations)**
*   **Определение:** Применение искусственного интеллекта и машинного обучения для анализа огромных объемов данных (логов, метрик, событий) с целью прогнозирования сбоев, автоматического определения корневой причины (RCA) и генерации решений.
*   **Источник:** Stencel Grzegorz, Berton Luca - Kubernetes Recipes - 2025

**Admission Controller (Контроллер допуска)**
*   **Определение:** Плагин в API-сервере Kubernetes, который выполняется во время создания или обновления ресурсов. Он может изменять (mutate) объект или полностью запрещать (validate) его создание на основе установленных политик.
*   **Источник:** Lapaz Raul - Learning Kubernetes Security, 2nd Edition - 2025

**Chaos Engineering (Хаос-инженерия)**
*   **Определение:** Дисциплина, которая повышает надежность системы путем проведения контролируемых экспериментов с намеренным внесением сбоев (например, удаление подов, введение сетевых задержек) для поиска слабых мест.
*   **Источник:** Burns B., Villalba E., Strebel D., Evenson L. - Kubernetes Best Practices - 2024

**CIS Benchmarks (Рекомендации CIS)**
*   **Определение:** Подробные, проверенные на практике руководства по безопасности, разработанные некоммерческой организацией Center for Internet Security (CIS). В контексте Kubernetes они содержат сотни рекомендаций по настройке компонентов кластера.
*   **Источник:** Lapaz Raul - Learning Kubernetes Security, 2nd Edition - 2025

**Container Escape (Побег из контейнера)**
*   **Определение:** Техника, с помощью которой злоумышленник, получивший контроль над процессом внутри контейнера, использует уязвимость для получения доступа к базовому хосту (узлу) и, как следствие, ко всему кластеру Kubernetes.
*   **Источник:** Lapaz Raul - Learning Kubernetes Security, 2nd Edition - 2025

**eBPF (extended Berkeley Packet Filter)**
*   **Определение:** Технология ядра Linux, позволяющая безопасно и эффективно выполнять песочницу (sandboxed) кода внутри ядра. Стала основой для современных инструментов наблюдаемости (Hubble), безопасности (Falco) и сети (Cilium).
*   **Источник:** Stencel Grzegorz, Berton Luca - Kubernetes Recipes - 2025

**GitOps**
*   **Определение:** Практика управления конфигурацией и развертыванием, при которой Git является единственным источником истины для желаемого состояния системы. Все изменения вносятся через pull-requests, что обеспечивает аудит, возможность отката и автоматизацию.
*   **Источник:** Vinto Natale, Bueno Alex Soto - GitOps Cookbook. Kubernetes Automation in Practice - 2023

**Imperсonaция (Impersonation)**
*   **Определение:** Механизм в Kubernetes, который позволяет одному пользователю или сервисному аккаунту выполнять операции в API от имени другого пользователя, группы или сервисного аккаунта, при наличии соответствующих прав.
*   **Источник:** Sayfan Gigi - Mastering Kubernetes, 4th Edition

**LLM (Large Language Model - Большая языковая модель)**
*   **Определение:** Тип искусственного интеллекта, обученный на огромных объемах текста, способный генерировать текст, отвечать на вопросы и писать код. В контексте безопасности используется для анализа логов и генерации отчетов на естественном языке.
*   **Источник:** Stencel Grzegorz, Berton Luca - Kubernetes Recipes - 2025

**NetworkPolicy (Сетевая политика)**
*   **Определение:** Объект Kubernetes API, который определяет правила для входящего (`ingress`) и исходящего (`egress`) трафика между подами. По умолчанию все поды могут общаться со всеми, `NetworkPolicy` позволяют явно разрешать или запрещать трафик.
*   **Источник:** Бранд А., Ландер Р., Россо Д., Харрис Д. - Kubernetes на практике - 2022

**Platform Engineering (Инженерия платформы)**
*   **Определение:** Создание внутренних платформ (Internal Developer Platforms - IDP), которые абстрагируют сложность Kubernetes и предоставляют разработчикам простые, безопасные и проверенные "строительные блоки" для развертывания приложений.
*   **Источник:** Stencel Grzegorz, Berton Luca - Kubernetes Recipes - 2025

**Pod Security Standards (PSS)**
*   **Определение:** Встроенные в Kubernetes стандарты безопасности для Pod'ов, заменившие устаревшие Pod Security Policies (PSP). Определяют три уровня строгости: `privileged`, `baseline` и `restricted`.
*   **Источник:** Lapaz Raul - Learning Kubernetes Security, 2nd Edition - 2025

**RBAC (Role-Based Access Control - Управление доступом на основе ролей)**
*   **Определение:** Механизм в Kubernetes, который определяет, кто (пользователь или сервисный аккаунт) может что делать (глагол: get, list, create) с какими ресурсами (pods, services) в каком namespace.
*   **Источник:** Burns B., Villalba E., Strebel D., Evenson L. - Kubernetes Best Practices - 2024

**SBOM (Software Bill of Materials - Спецификация материалов ПО)**
*   **Определение:** Машиночитаемый документ, который перечисляет все компоненты, библиотеки и зависимости, используемые в программном обеспечении (например, в контейнерном образе). Аналог "списка ингредиентов" для приложения.
*   **Источник:** Lapaz Raul - Learning Kubernetes Security, 2nd Edition - 2025

**Secrets (Секреты)**
*   **Определение:** Объект Kubernetes для хранения чувствительных данных, таких как пароли, токены и ключи. По умолчанию хранятся в etcd в виде Base64-кодировки, что не является безопасным.
*   **Источник:** Gkatziouras Emmanouil, Adams Rom, Xi Chen - Kubernetes Secrets Handbook - 2024

**Shift-Left Security**
*   **Определение:** Принцип, согласно которому процессы тестирования и безопасности переносятся на более ранние этапы жизненного цикла разработки (в левую часть диаграммы), чтобы выявлять и исправлять проблемы раньше и дешевле.
*   **Источник:** Burns B., Villalba E., Strebel D., Evenson L. - Kubernetes Best Practices - 2024

**Supply Chain Security (Безопасность цепочки поставок)**
*   **Определение:** Набор практик, направленных на обеспечение целостности и подлинности программного обеспечения на всех этапах его жизненного цикла: от исходного кода до развертывания в production.
*   **Источник:** Lapaz Raul - Learning Kubernetes Security, 2nd Edition - 2025

**Zero Trust (Ноль доверия)**
*   **Определение:** Концепция безопасности, которая предполагает, что угроза может исходить изнутри, и отвергает модель "доверяй внутри периметра". Принцип: "Никогда не доверяй, всегда проверяй".
*   **Источник:** Dubey S., Mandar J. Kulkarni - Hands-On Kubernetes, Service Mesh and Zero-Trust - 2023
