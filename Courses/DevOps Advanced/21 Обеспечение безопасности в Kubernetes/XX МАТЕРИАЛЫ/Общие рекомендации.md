#### **1. Официальная документация и проекты (Обязательные к изучению)**

*   **`Lapaz Raul - Learning Kubernetes Security, 2nd Edition (2025)`:** Самая актуальная и всесторонняя книга по теме. **Обязательна к прочтению.** Она покрывает все ключевые темы курса: PSS, PSA, Supply Chain Security, eBPF.
*   **Официальная документация Kubernetes (Раздел Security):** `https://kubernetes.io/docs/concepts/security/` — Ваш первый и главный источник истины. Всегда актуальна.
*   **Проект `inspektor-gadget`:** `https://github.com/inspektor-gadget/inspektor-gadget` — Документация и примеры использования одного из самых мощных инструментов для диагностики и безопасности на основе eBPF.
*   **Проект `kube-bench`:** `https://github.com/aquasecurity/kube-bench` — Официальный инструмент для аудита безопасности кластера по CIS Benchmarks.
*   **Проект Sigstore (`cosign`, `syft`):** `https://sigstore.dev/` — Документация по безопасности цепочки поставок, включая подпись образов и генерацию SBOM.

#### **2. Книги для углубленного изучения (Рекомендованные)**

*   **`Boorshtein Marc, Surovich Scott - Kubernetes An Enterprise Guide, 3rd Edition (2024)`:** Отличное руководство для инженеров в корпоративной среде. Глубоко погружается в темы безопасности, включая детальное сравнение PSA, Kyverno и OPA/Gatekeeper.
*   **`Stencel Grzegorz, Berton Luca - Kubernetes Recipes (2025)`:** Книга в формате "рецептов" с конкретными решениями для повседневных задач. Идеальна для быстрого поиска решений по настройке Network Policies, RBAC и другим аспектам безопасности.
*   **`Gkatziouras Emmanouil, Adams Rom, Xi Chen - Kubernetes Secrets Handbook (2024)`:** Специализированная книга, полностью посвященная управлению секретами — одной из самых критичных тем безопасности.
*   **`Burns B., Villalba E., Strebel D., Evenson L. - Kubernetes Best Practices (2024)`:** Практическое руководство от одного из создателей Kubernetes. Предоставляет четкие, применимые на практике рекомендации по безопасности.

#### **3. Инструменты для практики**

*   **`kind` или `minikube`:** Идеальные инструменты для создания локального кластера Kubernetes на вашем компьютере. Используйте их для отработки всех команд и настройки политик из курса.
*   **`kubectl` и `krew`:** Установите `krew` — менеджер плагинов для `kubectl`. С его помощью установите `kubectl-debug`, `kubectl-who-can` и другие плагины, упомянутые в курсе.
*   **`Trivy` и `Grype`:** Установите эти инструменты и попробуйте просканировать образы, которые вы используете в своих проектах.

#### **4. Онлайн-ресурсы и сообщества**

*   **CNCF Landscape:** `https://landscape.cncf.io/` — Карта всей экосистемы облачных нативных технологий. Отличный способ найти альтернативные инструменты и понять, где вписывается каждый проект.
*   **Kubernetes Slack и Reddit:** Активные сообщества, где можно задать вопросы, получить помощь и узнать о последних новостях.
*   **Блоги ведущих компаний:** Следите за блогами Aqua Security, Sysdig, Datadog, Google Cloud и Microsoft Azure. Они регулярно публикуют статьи о безопасности и новых трендах.
