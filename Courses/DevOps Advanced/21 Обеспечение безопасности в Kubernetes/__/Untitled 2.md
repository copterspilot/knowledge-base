### ✅ Что использовать из оставшихся 5 книг

#### 🎯 1. **Lapaz Raul — *Learning Kubernetes Security, 2nd Ed* (2025)**
- **Источник №1**
- Используй для:
  - **Pod Security Admission (PSA)**: уровни `privileged`, `baseline`, `restricted`
  - **NetworkPolicies**: L3/L4, интеграция с Cilium
  - **Supply chain security**: Trivy, SBOM, Cosign, Kyverno
  - **RBAC + OIDC**: продвинутая авторизация

#### 🎯 2. **Уильям Д. — *Kubernetes для разработчиков* (2025)**
- Из отрывка видно: упоминает **health checks, CVE, обновление контейнеров**
- Используй для:
  - **Примера сканирования на уязвимости (CVE)**
  - **Обновления образов с безопасными тегами** (не `latest`)
  - **Практических рекомендаций по жизнеспособности и безопасности**

#### 🎯 3. **Sachdeva Piyush — *CKA Study Companion* (2025)**
- Подготовка к сертификации → значит, **официальные best practices**
- Используй для:
  - **RBAC**: `Role`, `ClusterRole`, `RoleBinding`, `ClusterRoleBinding`
  - **NetworkPolicies**: синтаксис, поведение по умолчанию
  - **Pod Security**: как проверяется на экзамене CKA
  - **Audit logs**, **admission controllers**

#### 🎯 4. **Naik Sameer — *Kubernetes Cookbook, 2nd Ed* (2024)**
- Практические рецепты
- Используй для:
  - **Готовых манифестов** (RBAC, NetworkPolicy)
  - **Сценариев hardening**
  - **Интеграции с инструментами в CI/CD**

#### 🎯 5. **Kannaiah Govardhana — *Kubernetes Anti-Patterns* (2024)**
- Уникальный подход
- Используй для слайда:
  - **«5 самых опасных антипаттернов безопасности»**
    - Запуск от root
    - `latest` тег
    - Отсутствие NetworkPolicies
    - Избыточные права в ServiceAccount
    - Открытый API-сервер
