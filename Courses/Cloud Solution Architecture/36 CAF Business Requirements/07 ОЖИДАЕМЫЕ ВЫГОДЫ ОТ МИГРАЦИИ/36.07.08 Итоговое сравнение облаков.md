# 🌐 **Западные vs Российские vs Китайские**  
*Актуально на 2025 г.*

| Критерий                                | **Западные (AWS, Azure, GCP)**                                    | **Российские (Yandex Cloud, SberCloud, RT.Cloud)**    | **Китайские (Alibaba, Huawei, Tencent)**                |
| --------------------------------------- | ----------------------------------------------------------------- | ----------------------------------------------------- | ------------------------------------------------------- |
| **География присутствия**               | Глобальная (регионы по всему миру)                                | Только Россия и СНГ                                   | Азия (Китай, ЮВА), частично Европа и США                |
| **Локализация данных в РФ (ФЗ-152)**    | ❌ Только Azure (регион Москва)                                   | ✅ Полная поддержка всех провайдеров                  | ❌ Нет регионов в РФ (кроме партнёрских решений)        |
| **Работа с российскими госструктурами** | ⚠️ Ограничена                                                     | ✅ Полная поддержка (особенно RT.Cloud, SberCloud)    | ⚠️ Ограничена (требует партнёров)                       |
| **Поддержка русского языка**            | ❌ (AWS, GCP — англоязычные), ✅ (Azure — частично)               | ✅ Полная (документация, поддержка, интерфейс)        | ⚠️ Ограниченная (частичный перевод)                     |
| **Гибридное облако**                    | ✅ Отличная (Azure Arc, AWS Outposts)                             | ✅ Хорошая (SberCloud Edge, Rostelecom)               | ⚠️ Ограниченная (Huawei FusionCloud)                    |
| **Зрелость экосистемы**                 | ⭐⭐⭐⭐⭐ (наиболее зрелые и разнообразные сервисы)              | ⭐⭐⭐⭐ (хорошее развитие, но меньше сервисов)       | ⭐⭐⭐⭐ (быстро развивается, особенно в Китае)         |
| **AI / Машинное обучение**              | ✅ Продвинутые сервисы (SageMaker, Vertex AI, Cognitive Services) | ✅ Хорошие (Yandex Salute, Sber GigaChat, GigaSpeech) | ✅ Продвинутые (Tongyi, HunYuan, Pangu)                 |
| **Контейнеры / Kubernetes**             | ✅ Лидеры (EKS, AKS, GKE)                                         | ✅ Хорошие (Yandex Managed Kubernetes, SberCloud K8s) | ✅ Хорошие (ACK, TKE, CCE)                              |
| **Serverless**                          | ✅ AWS Lambda, Azure Functions, Cloud Functions                   | ✅ Yandex Functions, SberCloud Functions              | ✅ Function Compute, SCF, FunctionGraph                 |
| **Безопасность и соответствие**         | ✅ ISO, GDPR, HIPAA, SOC                                          | ✅ ФСТЭК, ФСБ, ISO 27001                              | ✅ PIPL (КНР), ISO, но нет ФСБ/ФСТЭК                    |
| **Санкционная устойчивость**            | ❌ Под санкциями (ограничения для РФ)                             | ✅ Не под санкциями                                   | ✅ Не под западными санкциями                           |
| **Доступность для российских компаний** | ⚠️ AWS и GCP ограничены, Azure — частично доступен                | ✅ Полный доступ                                      | ✅ Полный доступ (через международные аккаунты)         |
| **Цены**                                | ✅ Гибкие, но могут быть высокими                                 | ✅ Конкурентные, часто дешевле                        | ✅ Низкие, особенно в Азии                              |
| **Миграционные инструменты**            | ✅ Отличные (AWS Migrate, Azure Migrate)                          | ✅ Хорошие (Yandex Migrate, SberCloud Migrate)        | ✅ Хорошие (SMC, Migration Service)                     |
| **Интеграция с локальными сервисами**   | ❌ Ограничена                                                     | ✅ Отличная (Сбербанк, Яндекс, VK, Госуслуги)         | ✅ Отличная (WeChat, Alipay, Taobao)                    |
| **Поддержка DevOps и IaC**              | ✅ Terraform, CloudFormation, ARM, CLI                            | ✅ Terraform, API, CLI                                | ✅ Terraform, SDK, CLI                                  |
| **Производительность сети**             | ✅ Высокая                                                        | ✅ Хорошая (внутри РФ)                                | ✅ Отличная в Азии                                      |
| **Прозрачность и контроль**             | ✅ Хорошая                                                        | ✅ Высокая (особенно Selectel)                        | ⚠️ Ограниченная (особенно у Huawei — вопросы доверия)   |
| **Особенности**                         | Глобальные стандарты, инновации, масштаб                          | Локализация, безопасность, работа с госсектором       | Экосистема Alibaba/Tencent, промышленные решения Huawei |

## 🔚 Вывод

| Группа                            | Когда выбирать                                                                                                |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| **Западные (AWS, Azure, GCP)**    | Если вы работаете за пределами РФ, нужна максимальная функциональность и глобальная интеграция.               |
| **Российские (Yandex, Sber, RT)** | Если важна **локализация данных, безопасность, соответствие законодательству РФ и санкционная устойчивость**. |
| **Китайские (Alibaba, Huawei)**   | Если вы выходите на рынок Китая или Азии, или ищете **технологически зрелую альтернативу западным облакам**.  |

> 💡 **Оптимальная стратегия для многих российских компаний — гибридная**:  
> **Российское облако** для хранения ПДн и критичных систем + **Китайское или международное** — для глобальных сервисов.
