## 🔍 Пояснения по отраслям

### **1. Государственный сектор**
- **Лучшие**: **RT.Cloud** (ключевой провайдер госсектора), **SberCloud**, **Selectel** — все имеют сертификацию ФСТЭК/ФСБ.
- AWS/GCP не подходят из-за санкций и отсутствия локализации.

### **2. Финансовые услуги**
- **SberCloud** — лидер: интеграция с экосистемой Сбера, соответствие ЦБ, безопасность.
- **Yandex Cloud**, **RT.Cloud** — сильные альтернативы.
- Azure — возможен для международных банков с гибридной архитектурой.

### **3. Здравоохранение**
- **GCP** — сильный в AI/аналитике (например, анализ МРТ).
- **Yandex Cloud**, **SberCloud** — хороши для хранения данных в РФ и ИИ-диагностики (GigaMedical).
- Требуется ФЗ-152 и защита ПДн.

### **4. Образование**
- **Yandex Cloud** — лучший баланс цены, функциональности и поддержки русскоязычных пользователей.
- GCP и AWS — хороши для международных вузов.
- Поддержка LMS (например, Moodle, СДО) и видеоконференций критична.

### **5. Промышленность / IoT / Энергетика**
- **Huawei Cloud** — лидер: 5G, edge, промышленные решения.
- RT.Cloud, SberCloud — подходят для гибридных и защищённых сред.
- AWS — для международных проектов.

### **6. E-commerce и ритейл**
- **AWS, Alibaba, SberCloud, Yandex Cloud** — лидеры.
- Alibaba — для выхода на рынок Китая.
- SberCloud и Yandex — для интеграции с СберМаркетом, Яндекс.Маркетом, платёжами.

### **7. Телекоммуникации**
- **Huawei Cloud** — естественный выбор из-за интеграции с сетевым оборудованием.
- RT.Cloud, Selectel — для российских операторов.
- AWS/Azure — для международных проектов.

### **8. IT-стартапы и разработка ПО**
- **AWS, GCP, Yandex Cloud** — лучшие для DevOps, Kubernetes, serverless.
- Yandex Cloud — идеален для стартапов в РФ: низкий порог входа, хорошие managed-сервисы, AI.
- Multi-cloud и open-source подход снижают vendor lock-in.

### **9. Медиа и развлечения**
- **GCP, Tencent, Alibaba** — лидеры в обработке видео и стриминге.
- Tencent и Alibaba — ключ к китайскому рынку (WeChat, Douyin).
- Yandex Cloud — для локального контента и CDN в СНГ.

### **10. Международные компании в РФ**
- **Yandex Cloud** — лучший выбор: санкционно устойчив, функционален, поддерживает гибрид.
- SberCloud — для критичных данных.
- Azure — если нужна связь с глобальной инфраструктурой.
